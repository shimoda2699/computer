# コンピュータのしくみ（情報Ⅰ）

3つの教材を順番につなげたシリーズです。`index.html` から始めます。

| ステップ | ファイル | 内容 |
|---|---|---|
| トップ | `index.html` | 3ステップの案内と先生向けメモ |
| 1 | `pc-build/index.html` | PC組み立てチャレンジ（グループ対抗ゲーム） |
| 2 | `memory-race.html` | メモリ階層かけっこ（予想クイズ→かけっこ→待ち時間のたとえ→キャッシュ） |
| 3 | `calculater.html` | CPUが命令を実行するしくみ（レベル1〜3） |

`img/` は memory-race.html が使うイラストです。
memory-race.html と calculater.html は、以前の同名ファイルを置きかえるものです（URLはそのまま使えます）。
`device_checker.html` など、このフォルダにない既存ファイルはそのまま残してください。

## 数値のそろえ方
すべての教材で、CPU 4GHz の1回の処理を 0.25ナノ秒、メインメモリを 100ナノ秒（CPU約400回分）としています。
STEP3 の「待ち時間」は、メモリとのやりとり1回＝約7分（CPUの1回＝1秒とした場合）で換算しています。
